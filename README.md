# 천하통일 어택

[천하통일 디펜스](https://github.com/JaehoonChoi-KARI/samguk-defense)의 후속편입니다. 전작이 성을 지키는 수비였다면, 이번에는 **군주가 직접 군대를 이끌고 쳐들어가는 공격 액션**입니다. 가족이 개인적으로 쓰려고 만들었고, 기획은 아이가 손으로 쓴 기획서에서 시작했습니다(`DESIGN.md`).

- 아이패드용입니다. **키보드로 합니다**(블루투스 키보드). 키보드가 없으면 터치로도 됩니다: 마지막으로 쓴 입력에 맞춰 화면이 바뀝니다. 휴대폰도 가로로 들면 됩니다.
- 처음 시작할 때 군주(유비, 조조, 손권)와 난이도(쉬움, 보통, 어려움)를 고릅니다. 이 기기에서 엔딩을 한 번 보면 **지옥** 난이도가 열립니다. 이야기는 전작과 같습니다(군주마다 20지역, `js/stories.js`, 이야기책 `js/lore/`).

## 조작

| 키보드 | 터치 | 하는 일 |
|---|---|---|
| ← ↑ → ↓ | 왼쪽을 누르고 끌기(조이스틱) | 군주 움직이기 |
| Space (누르고 있으면 계속) | ⚔️ 버튼 | 공격 |
| 1 ~ 6 | 아래 그림 버튼 | 부대 부르기: 보병·창병·기마병·궁수·책사·투석기 |
| Q W E | 오른쪽 둥근 버튼 | 군주 특수능력 |
| A S D | 오른쪽 위 작은 버튼 | 아이템 |
| R | 돌격/모여라 버튼 | 부대가 스스로 앞으로(돌격) ↔ 군주 곁으로(모여라) |
| Esc 또는 P | ⏸ | 멈춤 |

PC에서는 마우스로 버튼을 눌러도 됩니다. 한글 입력 상태여도 키가 그대로 먹습니다(`js/input.js`).

## 규칙

- **이기기**: 길을 따라 쳐들어가 **성문**을 깨면 **적장**이 나옵니다. 적장을 쓰러뜨리면 이깁니다. 길가에는 적 진영(🗼 망루와 지키는 부대)이 있고, 성에서는 가끔 적 지원군이 나와 길을 따라 옵니다.
- **지기**: 군주가 쓰러지면 집니다. 맞지 않고 4초가 지나면 군주와 장수의 체력이 천천히 차오릅니다.
- **부대**: 1~6으로 군주 옆에 부릅니다. 병종마다 **다시 부르는 시간**이 있고(보병 3초, 창병 3초, 기마병 4.5초, 궁수 3.5초, 책사 5초, 투석기 6초: 아이 기획서), 전장에 한꺼번에 둘 수 있는 부대는 **통솔력**만큼입니다(보병 2, 기마병 3, 투석기 4 …). 부대가 쓰러지면 그만큼 다시 부를 수 있습니다. 전투 중 승급은 없습니다(직접 조종하면서 하기엔 어려워서).
- **돌격/모여라**: 돌격이면 부대가 스스로 앞의 적에게 가서 싸우되 군주보다 650 넘게 앞서가지 않습니다. 모여라면 군주 뒤에 모여 군주 가까이 온 적만 칩니다.
- **장수**: 정비에서 4명까지 골라 데려갑니다. 군주 곁을 따라다니며 스스로 싸우고 특수 능력을 씁니다. 쓰러지면 25초 뒤 돌아옵니다(`js/data.js`의 `GENERALS`, `GEN_SPECIALS`).
- **상성**: 병종 6개는 적도 똑같이 씁니다. 아주 강함 ▲▲ 2배, 강함 ▲ 1.4배, 약함 ▼ 0.7배, 아주 약함 ▼▼ 0.5배. 아주 강함은 고리입니다: 창병 ⇒ 기마병 ⇒ 궁수 ⇒ 책사 ⇒ 투석기 ⇒ 보병 ⇒ 창병. 투석기는 망루와 성문에 2.5배입니다.
- **군주 특수능력**(Q/W/E, 군주 Lv 1·3·6에 배움, 대기 45초, 대부분 15초 동안):
  - 유비: 인덕의 손길(전군 회복), 도원결의(쓰러진 장수 복귀, 장수 공격·방어), 형제의 칼날(군주·근접 부대 공격)
  - 조조: 패왕의 호령(전군 공격), 호표기 출격(정예 기병이 앞으로 달려 나가 짓밟고 기절), 질풍 행군(전군 이동·공격 속도)
  - 손권: 궁노 일제 사격(원거리 공격 속도), 화공(적이 가장 많은 곳에 불바다), 강동의 호랑이(군주 공격 크게, 전군 공격 조금)
  - 조준이 필요한 능력은 군주 가까이에서 적이 가장 많이 모인 곳(또는 앞쪽)을 알아서 노립니다.
- **아이템**(A/S/D): 💣 벽력탄(고른 병종의 적 한 부대를 바로 쓰러뜨림, 적장·망루 제외), 🥁 축제의 북(12초 동안 아군 공격 빠르게·체력 회복, 적 느리게), 📜 둔갑천서(히든: 망루를 부수면 가끔 나옴. 60초 동안 부대 2배 빨리 부르기, 적 5초 동안 꼼짝 못 함).
- **별**: 이겼을 때 군주 체력이 35% 이상이면 ★2, 70% 이상이면 ★3.
- **성장**: 병영(병종 강화), 군주 레벨(통솔력 8+레벨, 특수능력 위력), 군주 특성(군주·병종·전략 세 갈래, 언제든 되돌리기), 장비(무기·갑옷은 부대 전부와 군주에게 절반, 보물은 특수능력·장수·군주).
- **날씨·도전 과제**: 지역마다 날씨(동남풍·비·안개·밤·눈보라)와 도전 과제(망루 모두 부수기, 군주 체력 절반, 아이템 없이, ○분 안에 …)가 있습니다.

**플레이 주소: https://jaehoonchoi-kari.github.io/samguk-attack/**

아이패드 Safari에서 위 주소를 열고 공유 버튼 → "홈 화면에 추가"를 누르면 앱처럼 설치됩니다. 한 번 열고 나면 인터넷이 없어도 실행됩니다. 전작과 세이브가 따로입니다(`samgukAtk.*`).

## 실행

```powershell
pwsh -File serve.ps1          # http://localhost:8000, 같은 Wi-Fi 주소, Tailscale 주소를 출력
```

ES module을 쓰기 때문에 `index.html`을 더블클릭해서는 열리지 않습니다. 개발 중에는 휴대폰에서 Tailscale 주소로 열어 확인합니다.

## 자동 테스트와 밸런스 측정

- `http://localhost:8000/?autotest=1`: 60개 지역 데이터 검사, 봇 전투 18판(군주 3명 × 6지역), 화면 흐름 전체(처음 화면 → 슬롯 → 군주 → 이야기 → 본영 → 지도 → 정비 → 전투 → 조작법 안내 → 키보드 조작 → 터치 조작(버튼·조이스틱) → 버튼이 화면 안에 있는지 → 벽력탄 고르기 → 멈춤 → 그만두기 → 봇 전투 끝까지 → 결과). `bot=0`이면 봇 전투를 건너뜁니다.
- `tools/autotest.ps1`: 위 페이지를 헤드리스 Edge로 돌려 결과 JSON을 출력합니다(서버가 8000번에 떠 있어야 함). 휴대폰 크기는 `-Size "844,390" -Name phone`.
- `tools/shot.ps1 -Query "shot=battle&n=4"`: 장면을 고정해 스크린샷을 찍습니다. 장면: `title`, `slots`, `lord`, `base`, `map`, `prep`, `guide`, `battle`, `boss`, `result`. `lord=caocao`, `n=1..20`, `touch=1`(터치 화면), `t=40`(봇이 몇 초 싸운 뒤), `bomb=1`(벽력탄 고르기 창).
- `http://localhost:8000/tools/balance.html?diff=1&runs=4`: 봇이 각 지역을 "그 시점의 평범한 진행 상태"(권장 레벨, 골드를 병종 강화에 고르게, 장수 4명)로 플레이해 승률, 한 판 시간, 이겼을 때 남은 군주 체력을 냅니다. `lords=`, `stages=1-20`, `items=0`, `lvl=`, `troop=`. 헤드리스로는 `tools/autotest.ps1 -Url "http://localhost:8000/tools/balance.html?runs=3&diff=1" -Name bal`.

측정값(봇, 군주 3명 × 20지역 × 3회, v1.0.0, 아이템 사용):

| 난이도 | 승률 (다섯 지역씩) | 한 판 | 이겼을 때 군주 체력 |
|---|---|---|---|
| 쉬움 | 100% (100·100·100·100%) | 약 2분 10초 | 약 80% |
| 보통 | 100% (100·100·100·100%) | 약 2분 50초 | 약 70% |
| 어려움 | 96% (100·100·100·84%) | 약 3분 50초 | 약 68% |
| 지옥 | 92% (100·93·93·82%) | 약 5분 | 약 68% |

봇은 늘 상성에 맞는 부대를 부르고 통솔력을 꽉 채워서, 사람보다 잘합니다. 목표 난이도는 직접 해 보고 정합니다. 조절 값: `js/data.js`의 `FOE_HP`·`FOE_ATK`(적 부대), `TOWER`, `CASTLE`(성문), `BOSS`, `EARLY_EASE`(1~3지역 성문·적장 가볍게), `REINFORCE`(지원군), `campCount`·`campGuards`, `DIFFS`, `leadership`, `TROOPS[...].summonCd`, `LORD_STATS`.

## 새 버전 배포

1. `js/data.js`의 `VERSION`과 `sw.js`의 `CACHE`를 같은 새 버전으로 올립니다.
2. 자동 테스트가 통과하는지 봅니다(`main`에 올리면 바로 아이패드로 갑니다).
3. 커밋하고 `main`에 push합니다. GitHub Pages가 1~2분 안에 반영합니다.
4. 기기는 인터넷이 연결돼 있으면 게임을 켤 때 최신 버전을 받습니다. 처음 화면의 버전 버튼을 누르면 바로 업데이트를 확인합니다.
